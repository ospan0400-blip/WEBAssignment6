# Web Assignment 6 — jQuery

This project demonstrates basic jQuery functionality, including DOM manipulation, event handling, effects, animations, and a small interactive mini project.

## Project Structure

- `part1.html` — jQuery basics: selecting elements and changing CSS, HTML, and text.
- `part2.html` — jQuery effects: hide/show/toggle, fade effects, and slide effects.
- `part3.html` — DOM manipulation:
  - Add, prepend, and remove list items.
  - Change an image's `src` and a link's `href`.
  - Display Name and Email input values live.
- `part4.html` — jQuery animations:
  - Basic size and position animation.
  - Sequential animations.
  - Combined movement, size, and opacity animation.
- `part5.html` — Mini project: a bouncing ball that moves back and forth, with Start and Stop buttons.
- `part3.css`, `part4.css`, `part5.css` — styles for Parts 3–5.
- `treeforassignemnt.jpg`, `pyramidforassignemtn.jpg`, `secondspyramidforassignemtn.webp` — images used in the project.

## Technologies

- HTML
- CSS
- jQuery 3.7.1 (loaded through the Google CDN)

## How to Run

1. Download or clone the project.
2. Keep the HTML, CSS, and image files in the same project folder.
3. Open `part1.html`, `part2.html`, `part3.html`, `part4.html`, or `part5.html` in a web browser.
4. Use the buttons and inputs on each page to try the jQuery features.

An internet connection is required to load jQuery from the CDN.

## Learning Objectives

- Use jQuery selectors and document-ready functions.
- Respond to user actions with event handlers.
- Update page content and attributes.
- Read form values and display them dynamically.
- Apply jQuery effects and chained animations.
